# Proyecto Examen PGY2131

Proyecto académico desarrollado en el contexto de la asignatura PGY2131, como parte de la formación en Analista Programador Computacional en Duoc UC.

## 📌 Descripción

Este repositorio contiene el desarrollo realizado para la evaluación de la asignatura. El proyecto permitió aplicar conocimientos de programación y desarrollo de software en la resolución de los requerimientos planteados para el examen.

## 🛠️ Tecnologías utilizadas

Las tecnologías, herramientas y frameworks utilizados se detallan de acuerdo con la implementación del proyecto.

## ⚙️ Funcionalidades

Las funcionalidades de la aplicación corresponden a los requerimientos definidos para la evaluación y a las características implementadas en el código fuente.

## 🚀 Instalación y ejecución

Para ejecutar el proyecto localmente:

1. Clonar este repositorio.
2. Revisar los archivos del proyecto y los requisitos necesarios para su ejecución.
3. Instalar las dependencias correspondientes, si las hubiera.
4. Seguir las instrucciones de configuración y ejecución según la tecnología utilizada.
